# ระบบประเมินผลการฝึก กรมพระธรรมนูญ

## มีอะไรในชุดนี้
- แบบประเมิน 5 ด้าน ด้านละ 1–5 คะแนน
- ทะเบียนประวัติ ค้นหา และลบรายการ
- รายงานคะแนนเฉลี่ย สรุปตามหัวข้อ ส่งออก CSV และพิมพ์ PDF
- ออกแบบรองรับมือถือ
- เชื่อม Supabase เพื่อใช้ข้อมูลร่วมกันหลายคนได้เมื่อกำหนดค่าแล้ว

## วิธีติดตั้งบน GitHub Pages
1. สร้าง/เลือก repository ที่ต้องการใช้
2. อัปโหลด `index.html`, `style.css`, `script.js`, `config.js`, `supabase-schema.sql`, `README.md` ไว้ใน root
3. ไปที่ Settings → Pages → Deploy from a branch → เลือก `main` และ `/(root)` → Save

## เปิดใช้ข้อมูลร่วมกัน
1. สร้างโปรเจกต์ Supabase ที่ https://supabase.com/
2. รัน `supabase-schema.sql` ใน SQL Editor
3. ไป Project Settings → API แล้วคัดลอก Project URL และ anon/public key
4. ใส่ค่าลง `config.js` แทนข้อความตัวอย่าง แล้ว commit ขึ้น GitHub
5. เปิดเว็บใหม่และลองบันทึกข้อมูล

## ข้อจำกัดและความปลอดภัย
GitHub Pages เป็นโฮสต์เว็บไซต์ static ไม่ใช่ฐานข้อมูล หากยังไม่ตั้ง Supabase ระบบจะบันทึกเฉพาะเบราว์เซอร์อุปกรณ์นั้น ไม่แชร์ข้ามคนได้ ไฟล์ SQL นี้มีนโยบายสาธารณะสำหรับทดสอบเท่านั้น โดยผู้เข้าชมที่มี anon key อาจอ่าน เพิ่ม หรือลบข้อมูลได้ ห้ามใช้ข้อมูลจริงหรือข้อมูลส่วนบุคคลจนกว่าจะตั้ง Supabase Auth และนโยบาย RLS แบบจำกัดสิทธิ์สำหรับผู้ประเมิน/ผู้ดูแลอย่างเหมาะสม ห้ามนำ service_role key ใส่ในเว็บไซต์หรือ GitHub
