เชื่อมต่อฐานข้อมูลออนไลน์

GitHub Pages ให้บริการเว็บไซต์ แต่ไม่ได้เก็บข้อมูลร่วมกันโดยตัวมันเอง ต้องตั้งค่า Supabase เพื่อให้ผู้ประเมินเห็นข้อมูลชุดเดียวกัน

  1. สร้างโปรเจกต์บน Supabase
  2. รันไฟล์ supabase-schema.sql ใน SQL Editor
  3. แก้ค่าตัวแปรใน config.js ด้วย Project URL และ anon/public key
  4. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub แล้วเปิด Settings → Pages → main → /(root)

นโยบาย SQL ตัวอย่างเปิดสิทธิ์สาธารณะสำหรับทดสอบเท่านั้น ห้ามใช้ข้อมูลจริงจนกว่าจะตั้งระบบเข้าสู่ระบบและสิทธิ์ RLS ให้เหมาะสม ห้ามใส่ service_role key ในเว็บไซต์
